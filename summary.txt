BUILD / DEPLOY
------------------------------------------------------------
vite.config.js: base "/", plugins [vue(), csp].
  csp plugin -- build-only (apply: 'build'). Injects a Content-Security-Policy
  <meta> at build time (not in dev, which needs inline scripts + ws for HMR).
  Policy allows: self, inline scripts/styles, data: images, google.com frames
  (map embed), and api.web3forms.com for form connect/action.
Deployed to GitHub Pages. index.html includes the spa-github-pages redirect
  shim (rewrites ?/ query back to a real path) so deep links work on Pages.


SEO / META (index.html)
------------------------------------------------------------
lang="es". Static head includes: description, author, keywords, canonical,
  full Open Graph block, Twitter Card (summary_large_image), and a JSON-LD
  Organization schema (name, alternateName CIFEJ, founded 1999, 68 members,
  areaServed Jalisco/MX, contact email). Favicon: /img/favicon/favicon_multi.ico.
Per-route meta is then updated live by the router (see ROUTING).


ROUTING
------------------------------------------------------------
createWebHistory("/") -- SPA. Routes lazy-loaded via import() per route.
Each route defines meta: title, description, canonical (except 404: title only).
  SUFFIX const = " — Colegio de Ingenieros Forestales de Jalisco"
  BASE_URL const = "https://ingenierosforestales.com"
router.afterEach(to) updates on every navigation:
  - document.title
  - <meta name="description">, og:description, twitter:description
  - <link rel="canonical">, og:url
  - og:title, twitter:title
linkExactActiveClass: "active" (underline on active nav link); linkActiveClass: "".
scrollBehavior: () => ({ top: 0 }) -- always scroll to top on navigate.


COMPOSABLES
------------------------------------------------------------
useMotion()
  Queries all [data-motion] elements on mount.
  Supported values: fade-up, fade-down, fade-left, fade-right, zoom-in,
    flip-left, flip-right.  (Unknown/absent value falls back to fade-up.)
  inView fires once, removes .motion-pending, then runs Motion One animate().
  duration: 0.7s, easing: cubic-bezier(0.25, 0.46, 0.45, 0.94), margin: -80px.
  Cleanups run on unmount.

useSlider(count, interval = 8000)
  Returns: current (ref), goTo, prev, next, onTouchstart, onTouchend.
  Autoplay via setInterval (interval 0 = no autoplay); restarts on manual nav.
  Touch swipe: threshold 50px.
  Modular arithmetic keeps index in range.
  Used in: HomeView (testimonials carousel) and ServicesView (SEMARNAT slider).


DIRECTIVES
------------------------------------------------------------
v-lazy (vLazy.js)
  Usage: <img v-lazy="'/img/photo.webp'" alt="...">
  IntersectionObserver with rootMargin: 200px.
  Deferred placeholder: parent .gallery-item gets .show-placeholder after 300ms;
    removed on load (avoids flash for fast loads).
  .loaded added to <img>; .img-loaded added to .gallery-item (Firefox fallback).
  Falls back to direct src set if IntersectionObserver is unavailable.
  Used in: GalleryView.


CSS ARCHITECTURE
------------------------------------------------------------
Design tokens (base.css :root):
  --color-beige: #efe8d0
  --color-green: #204032
  --color-brown: #503a34
  --color-gray:  #cfcfcf
  --font-titles: Raleway
  --font-body:   Nunito

Fluid typography via clamp() (--text-sm through --text-4xl), no per-breakpoint
  font-size overrides needed.
Fluid spacing: --gap-sm / --gap-md / --gap-lg.
--text-inst: dedicated token for the institution name string in the header.

components.css: shared classes used across views:
  .section-title / .section-body -- typography helpers
  .page-banner / .banner-bg -- inner page banner pattern
  .bg-section -- full-bleed background image section
  .btn, .btn-beige, .btn-green, .btn-white -- CTA buttons
  .nav-arrow, .nav-arrow--dark, .nav-arrow--light -- carousel arrows
  .nav-dot, .nav-dot--dark, .nav-dot--light -- carousel dots
  .cta-container / .cta-content / .cta-icon -- shared CTA block (Galeria, others)
  .card -- generic white card
  .vignette-container, .cta-icon, .banner-icon, .testimonial-icon -- decorative
    image vignettes (hidden on mobile < 768px)
  .bullet-list li -- list items with webp vignette bullet via ::before pseudo

[data-motion].motion-pending { opacity: 0 } is set in base.css (not JS) to
  prevent FOUC when the bundle arrives late.

Single breakpoint at 767px (max-width) handles all responsive layout changes.
Scoped <style> per view for local overrides.


VIEWS
------------------------------------------------------------
HomeView (/):
  Sections: main hero banner, welcome text + image, membership columns (4 icons),
  "Nuestra Causa" (3 bullet points), "¿Por qué escogernos?" (25 years copy),
  testimonials carousel (3 slides, 8s autoplay, touch swipe).

AboutView (/nosotros):

ServicesView (/servicios):
  Sections: intro, "Trámites ante SEMARNAT" slider (11 services via useSlider,
  8s autoplay, touch swipe), "Trámites ante CONAFOR" cards (2), CTA.
  Data: inline arrays semarnatServices / conaforCards.

GalleryView (/galeria):
  6 categories: Inventario (15 imgs), Aprovechamiento (6), Transformación (15,

  Lightbox: click to open, keyboard (Esc/arrows), touch swipe, click-outside close.

    Locks body scroll while open.

  Uses useMotion().

ContactView (/contacto):
  Sections:
    - Google Maps embed (iframe) of the Cd. Guzmán, Jalisco office.
    - Contact info: address, phone (tel: link), email
      (colegioingenierosforestalesjal@gmail.com).
    - Contact form POSTing to Web3Forms (api.web3forms.com/submit) with a hidden
      access_key; native HTML5 validation + focus/valid/invalid styling.
    - FAQ accordion: native <details>/<summary>, CSS-only +/- icon, 3 questions
      (inline faqs array). No JS state.
  Uses useMotion().

NotFoundView (/:pathMatch(.*)*):
  404 page. Title: "Página no encontrada — CIFEJ".
