scrollBehavior: () => ({ top: 0 }) -- always scroll to top on navigate.
Lazy-loaded views (import() per route).


COMPOSABLES
------------------------------------------------------------
useMotion()
  Queries all [data-motion] elements on mount.
  Supported values: fade-up, fade-down, fade-left, fade-right, zoom-in,
    flip-left, flip-right.
  inView fires once, removes .motion-pending, then runs Motion One animate().
  duration: 0.7s, easing: cubic-bezier(0.25, 0.46, 0.45, 0.94), margin: -80px.
  Cleanups run on unmount.

useSlider(count, interval = 8000)
  Returns: current (ref), goTo, prev, next, onTouchstart, onTouchend.
  Autoplay via setInterval; restarts on manual nav.
  Touch swipe: threshold 50px.
  Modular arithmetic keeps index in range.
  Used in: HomeView (testimonials carousel).


DIRECTIVES
------------------------------------------------------------
v-lazy (vLazy.js)
  Usage: <img v-lazy="'/img/photo.webp'" alt="...">
  IntersectionObserver with rootMargin: 200px.
  Deferred placeholder: parent .gallery-item gets .show-placeholder after 300ms;
    removed on load (avoids flash for fast loads).
  .loaded added to <img>; .img-loaded added to .gallery-item (Firefox fallback).
  Falls back to direct src set if IntersectionObserver is unavailable.
  Used in: GalleryView.


CSS ARCHITECTURE
------------------------------------------------------------
Design tokens (base.css :root):
  --color-beige: #efe8d0
  --color-green: #204032
  --color-brown: #503a34
  --color-gray:  #cfcfcf
  --font-titles: Raleway
  --font-body:   Nunito

Fluid typography via clamp() (--text-sm through --text-4xl), no per-breakpoint
  font-size overrides needed.
Fluid spacing: --gap-sm / --gap-md / --gap-lg.
--text-inst: dedicated token for the institution name string in the header.

components.css: shared classes used across views:
  .section-title / .section-body -- typography helpers
  .page-banner / .banner-bg -- inner page banner pattern
  .bg-section -- full-bleed background image section
  .btn, .btn-beige, .btn-green, .btn-white -- CTA buttons
  .nav-arrow, .nav-arrow--dark, .nav-arrow--light -- carousel arrows
  .nav-dot, .nav-dot--dark, .nav-dot--light -- carousel dots
  .cta-container / .cta-content / .cta-icon -- shared CTA block (Galeria, others)
  .card -- generic white card
  .vignette-container, .cta-icon, .banner-icon, .testimonial-icon -- decorative
    image vignettes (hidden on mobile < 768px)
  .bullet-list li -- list items with webp vignette bullet via ::before pseudo

[data-motion].motion-pending { opacity: 0 } is set in base.css (not JS) to
  prevent FOUC when the bundle arrives late.

Single breakpoint at 767px (max-width) handles all responsive layout changes.
Scoped <style> per view for local overrides.
